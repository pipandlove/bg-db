# Foxamon `.mat`

Same notation as OpenGammon (`25` bar, `0` off, one entry per checker, empty `34:` for a dance), but a narrower
layout (right cell at column 41) and fewer header tags (no `EventDate`; the date is only in the file name of the
fixtures). A double can be re-doubled in the other column (`Doubles => 2 / Takes / Doubles => 4`). Final value
capped at the points needed.

Fixtures: [`fixtures/foxamon/`](../../fixtures/foxamon) (2 matches, both with a `.xg`).
